# TCA4SHOP | Landing Page Premium

Landing page de alto rendimiento diseñada para **TCA4SHOP**, una tienda de tecnología premium en Guatemala.

## 🚀 Características
- **Diseño Apple-Style**: Estética limpia, tipografía moderna y espacios equilibrados.
- **Micro-animaciones**: Efectos de paralaje 3D en el Hero, Scroll Reveal y transiciones suaves.
- **Optimizado para Conversión**: Embudos directos a WhatsApp y diseño mobile-first.
- **Estructura Profesional**: Organización de archivos limpia (CSS, JS, Assets).

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript Vanilla (Interactivity & Animations)

## 📦 Estructura del Proyecto
```text
├── assets/
│   └── img/           # Imágenes de productos
├── css/
│   └── styles.css     # Estilos globales
├── js/
│   └── script.js      # Lógica y animaciones
└── index.html         # Página principal
```

## 🌐 Despliegue
Este proyecto está listo para ser desplegado en **GitHub Pages**.
